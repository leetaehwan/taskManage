# Task Management

30분 단위 일정 관리 플러터 앱
1. 앱 개요

앱 이름: TimeBlock
목적: 30분 단위로 일정을 시각화하고 관리할 수 있는 직관적인 일정 관리 앱
주요 기능: 30분 단위 블록으로 일정 표시, 빈 시간 확인 및 새 일정 추가

2. 주요 화면 구성
메인 화면 (일정 타임라인)

화면 왼쪽에 시간대 표시 (00:00 ~ 23:30, 30분 단위)
우측에 각 시간대별 일정 블록 표시
일정이 있는 블록은 색상으로 구분되며, 빈 블록은 비어있음
화면 상단에 날짜 선택 및 보기 옵션 제공

일정 추가 화면

시작 시간 선택 (30분 단위)
일정 지속 시간 선택 (블록 수로 표현, 예: 2블록 = 1시간)
일정 제목 및 설명 입력
일정 카테고리/색상 선택 옵션

3. 핵심 기능 상세
블록 표시 기능

각 블록은 30분 단위로 고정
연속된 블록은 2개~4개씩 묶어서 표시 가능 (사용자 설정)
일정이 있는 블록은 해당 일정의 색상과 제목 표시
블록을 탭하면 해당 시간대의 상세 정보 확인 가능

일정 추가 기능

빈 블록을 탭하여 일정 추가 화면으로 이동
시작 시간은 선택한 블록의 시간으로 자동 설정
블록 수(지속 시간) 선택 가능: 1블록(30분) ~ 최대 48블록(24시간)
반복 일정 설정 옵션

블록 뷰 조정 기능

블록 묶음 설정: 2개(1시간), 3개(1시간 30분), 4개(2시간) 옵션
표시 시간대 범위 조정 (예: 업무 시간만 표시, 전체 24시간 표시)
주간/월간 확장 뷰 옵션

4. UI/UX 디자인 방향

미니멀하고 직관적인 디자인
드래그 앤 드롭으로 일정 조정 가능
색상 코딩으로 일정 카테고리 구분
빈 시간 블록은 밝은 색상, 일정 블록은 진한 색상으로 대비

5. 기술적 구현 사항

Flutter 프레임워크 활용
로컬 데이터베이스(SQLite)를 통한 일정 저장
캘린더 위젯 연동 가능
알림 기능 구현

6. 추가 고려 사항

다크/라이트 테마 지원
일정 통계 및 분석 기능
다른 캘린더 앱과의 동기화 옵션
위젯 지원으로 홈 화면에서 일정 확인 가능

이 기획서를 바탕으로 사용자가 30분 단위로 시간을 효율적으로 관리하고, 빈 시간을 쉽게 파악하여 새로운 일정을 추가할 수 있는 직관적인 플러터 앱을 개발할 수 있습니다.
